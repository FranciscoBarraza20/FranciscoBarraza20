## Sobre mí

Estudiante de Ingeniería en Computación e Informática en la Universidad Católica del Norte (UCN), enfocado en el desarrollo de software y con un interés particular en **ciberseguridad** y **machine learning**.

Me interesa entender los sistemas a fondo: tanto construirlos de forma robusta como identificar sus puntos débiles. Actualmente combino el desarrollo backend con Node.js/Express y ASP.NET Core con el estudio autodidacta de seguridad ofensiva/defensiva y fundamentos de ML aplicados a problemas reales.

- 🔐 Explorando análisis de vulnerabilidades, hacking ético y hardening de sistemas
- 🤖 Aprendiendo los fundamentos de machine learning con Python
- 💻 Construyendo APIs y servicios backend como práctica constante
- 📚 Aprendizaje continuo como eje central de mi formación
