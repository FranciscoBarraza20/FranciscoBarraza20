## Sobre mí

Soy estudiante de **Ingeniería en Computación e Informática**, enfocado en fortalecer mis competencias en desarrollo de software y construcción de aplicaciones web.

Actualmente trabajo con tecnologías del ecosistema **React, TypeScript, C# y .NET**, además de Node.js y bases de datos relacionales. Paralelamente, estoy ampliando mis conocimientos en **Machine Learning y Ciberseguridad**.

Me interesa desarrollar software con buenas prácticas de programación, priorizando la legibilidad del código, la mantenibilidad, la seguridad y la calidad de las soluciones.

## En qué estoy trabajando

- **Desarrollo Full Stack:** construcción de aplicaciones web, integración entre frontend y backend, y diseño de API REST.
- **Backend y bases de datos:** desarrollo con ASP.NET Core, Node.js y Express, junto con bases de datos relacionales.
- **Machine Learning:** exploración de algoritmos de aprendizaje automático y sus aplicaciones en problemas reales.
- **Ciberseguridad:** aprendizaje de fundamentos de seguridad informática, sistemas Linux y entornos virtualizados.
