### 🌌 ASTRAL
**Machine Learning y ciencia de datos para astronomía**

Descarga de datos de estrellas y exoplanetas, reconocimiento de fuentes en imágenes FITS, estimación física de habitabilidad y entrenamiento de modelos de screening.

**Impacto**
- Habitabilidad física con Kopparapu + Monte Carlo
- MLP en PyTorch evaluado con MAE, PR-AUC y ROC-AUC
- API HTTP local para inferencia

**Stack:** `Python` · `PyTorch` · `scikit-learn` · `Astropy` · `pandas` · `pytest`

**Datos:** Gaia DR3 · SkyView DSS2 · NASA Exoplanet Archive
