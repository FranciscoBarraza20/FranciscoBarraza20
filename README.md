Me interesa el ciclo completo: **encontrar la falla, entender su impacto real y proponer la mitigación** — no solo correr un scanner y listo.

## 🤖 Machine Learning aplicado a Ciberseguridad

No me interesa el ML "genérico": me interesa el ML que **resuelve un problema de seguridad real**.

- 🧠 **Detección de anomalías** — Modelos de clasificación para identificar tráfico de red o comportamientos fuera de patrón (intrusiones, malware, exfiltración de datos).
- 🎣 **Detección de phishing / URLs maliciosas** — Ingeniería de características a partir de dominios, headers y estructura de páginas para clasificar amenazas antes del clic.
- 📊 **Análisis exploratorio de datasets de seguridad** — Limpieza y visualización de datasets tipo NSL-KDD / CICIDS para extraer señales útiles de ataque.
- ⚔️ **SecOps + ML** — Prototipos que integran reglas tradicionales (SIEM-style) con modelos predictivos para reducir falsos positivos.

> 💡 *Objetivo a mediano plazo: construir un pipeline propio que tome tráfico de red en crudo y devuelva un score de riesgo usando modelos entrenados por mí.*
