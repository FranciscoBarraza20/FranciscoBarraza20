### ASTRAL

Desarrollo de un proyecto de Machine Learning orientado a la identificación de exoplanetas análogos a la Tierra a partir de sus características físicas, utilizando catálogos oficiales de la NASA y Gaia DR3. Combina modelos de similitud, simulaciones Monte Carlo de zona habitable y una red neuronal de clasificación construida en PyTorch.

**Tecnologías:** `Python` `PyTorch` `Scikit-Learn` `Pandas` `NumPy`

### ORGANIZADOR CURRICULAR INTELIGENTE

Aplicación web full-stack diseñada para la gestión académica universitaria: administración de malla curricular, seguimiento de asignaturas, cálculo de calificaciones por semestre y calendario interactivo. Cuenta con importación automática de horarios desde archivos Excel, autenticación local y mediante Google OAuth, junto con almacenamiento de datos y personalización por usuario.

**Tecnologías:** `Node.js` `Express` `React` `SQLite` `Excel Parsing`
